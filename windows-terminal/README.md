# Windows Terminal

`pablo-workspace.json` contains the color scheme used by this setup.

## Installation

1. Open Windows Terminal.
2. Press `Ctrl+,`.
3. Select **Open JSON file**.
4. Copy the object from `pablo-workspace.json` into the top-level
   `schemes` array.
5. Select **Pablo Workspace** under the Ubuntu profile's Appearance settings.
6. Set the font face to **Cascadia Code NF**.

Recommended appearance:

- Font size: 11
- Cursor shape: Bar
- Background opacity: 96–100%
- Acrylic: Off
